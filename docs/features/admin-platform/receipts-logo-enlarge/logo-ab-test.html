Receipt logo — where does the gray box come from?

Four renders of the same receipt. A and C use byte-identical CSS (the 64px box shipping today); only the image file differs. If the gray were our container styling, it would appear in C too.

Logo assets are the real pixels lifted from the reported screenshot, so A is pixel-faithful to production. The "transparent" asset is that same mark with the gray field flood-filled out and trimmed — i.e. what a correct export looks like.
