<decisions_made>

- Primary query table is `order_payments` (not `orders`) so payment data is natively available
- Filter sheet uses local state + "Apply Filters" button (not live-filter on every change) — avoids excessive refetches
- URL params as source of truth for all filter state (shareable, back-button safe)
- `SheetTrigger asChild` was abandoned — Radix focus trap + Badge child caused silent click failure
- `DropdownMenu modal={false}` required to allow dropdowns to work inside Sheet
- `z-[200]` needed on DropdownMenuContent (Tailwind v4 arbitrary value) to render above Sheet overlay (z-[60])
  NOTE: Previous code used `z-200` — may need to fix to `z-[200]` if dropdowns appear behind overlay
- Error handling: return empty array instead of throw to avoid TanStack Query error state on DB issues

</decisions_made>

<blockers>

- Search across `customer_name` / `order_number` blocked by PostgREST limitation — can't span primary + embedded table in single `.or()`. Fix: DB view (see remaining_work).
- `z-200` class may be invalid in Tailwind v4 (should be `z-[200]`) — dropdowns inside sheet may render behind overlay on some Tailwind builds.

</blockers>
